# HAHA ATLAS · 美国大件设备物流指挥台

> 这是一个**独立版本**，与 V13（`haha-logistics-dispatch/v13`）不是同一个系统：
> ATLAS 不用 Pyodide、不载入任何外部瓦片服务，全部为纯静态前端 + 自绘 Albers 投影地图。

面向哈哈便利美国大件设备（智能售货柜/冷藏柜）的**海运在途 + 末端派送**一体化指挥台。
把 V12 方案里的服务档（L1–L5）、物流路径（A / B / C1 / C2）、头程环节（S01–S04）、
履约作业码（F01–F08）与批次签批门槛（P1–P4）做成可点击、可推演的操作界面。

## 功能

| 视图 | 内容 |
| --- | --- |
| **指挥总览** | 今日态势、待派/在途、未来 7 天到港与窗口密度、网络负载、服务档构成、今日队列 |
| **地图调度** | 明亮风格、真实道路底图（Leaflet + Esri World Street Map / OpenStreetMap 瓦片，带路网、地名与地形）；左侧结果列表 + 右侧情境检视器 + 底部派车计划条；列表行可直接「＋」加入计划；派车计划器：选站 → 自动站序（按窗口 / 最近邻）→ 逐段里程·行驶·等待·到场时间 → 窗口冲突 → 合车成本 vs 分票直送 → 生成派车单；点位密集时自动聚合 |
| **海运在途** | S01→REC 五列甘特式看板；拖拽推进环节；免箱期倒计时；12 项单证回执勾选；到港与免期窗口甘特；CSV 导出 |
| **路径与比价** | A/B/C1/C2 同范围全价对比、可行性阻断原因（L3 室内机位不能走普通卡派、L4 楼梯、84 in 限高）、DFW-Q01 样单复核、服务菜单、七型号与承运初筛 |
| **异常与返修** | F06 分诊顺序、保管责任人分布、SLA 计时、现场上门 vs 搬机返修成本临界计算器 |
| **结算复盘** | 批次净额瀑布图、单台新全费、账单差异表、签批门槛、六台合批激励上限演算 |
| **作业手册** | F01–F08 交互式作业码、岗位权限、P1–P4 周期、S01–S04 交接、KPI 口径、随单凭证 |

## 交互

- 滚轮缩放 / 拖动平移 / 双击放大；点击订单点、仓库点、港口点分别打开详情、切换起运仓、跳转海运看板。
- 顶部**推演时钟**：可"推进一天"或自动播放（1.5 s/天），免期、ETA、窗口全部按该日期重算。
- 明暗两套主题；移动端侧栏收起为抽屉；`1`–`7` 键切视图，`/` 聚焦搜索，`Esc` 关抽屉。
- 进度保存在 `localStorage`；顶栏"重置"可恢复初始演示数据。

## 技术

- 纯静态：`index.html` + 原生 CSS/JS，无构建步骤、无运行时依赖。
- 地图：Leaflet 1.9.4（BSD-2，已内置）+ 栅格瓦片底图。
  - 首选 Esri World Street Map（含路网、地名、地形），失败自动切 OpenStreetMap 标准瓦片；
  - 两者都不可用时，退回内置的州界示意底图（`assets/geo/us-states.js`），界面仍可用。
  - 底图版权：© Esri, HERE, Garmin, © OpenStreetMap contributors —— 页脚已标注。
- 覆盖物（仓库、订单、聚合点、路线、海运喂给航线）全部由本地数据在浏览器端绘制，不依赖任何接口。

## 身份与配色

- **明亮主题为默认**（白底、蓝色主色 `#2563eb`），标题栏、侧栏、卡片、表格均为浅色；
- 顶栏可切换深色主题，供夜间值班或投屏使用。

## 本地预览

```bash
# 任选其一
python -m http.server 8977
npx serve .
```

然后打开 <http://127.0.0.1:8977/>。

**单文件离线版**：打开 `standalone.html`（CSS / JS / 地图数据全部内联，双击即可，无需服务器、无需联网）。
适合发给不方便访问外网的同事，或投屏演示。

## 数据说明

**本仓库全部为演示数据**：订单、航次、发票、异常均为固定种子生成的合成样本。
费率卡锚定 V12 方案中的 DFW-Q01 样单（365/145、310/100、225/85）、LXD 分区价、
Long Road 拆柜与托位费、ResQ/Nodak 维修条款，用于演示核算口径，
**不构成任何一方的报价、承诺或实测声明**。
